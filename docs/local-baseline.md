# 本地基线 v1

2026-10-26。用户选择先完成本地基线，云端服务暂未确定。本版本提供数据处理、统计画像及真实历史检索；尚未提供生成式聊天。

## 启动

在项目根目录的 PowerShell 执行：

```powershell
.\scripts\start-local.ps1
```

浏览器访问 http://127.0.0.1:8765 。按 Ctrl+C 停止。服务仅绑定本机；查询不持久化，无云端请求。网页只展示训练部分的相关前文、本人历史回复及来源，不能将它当作当前观点或新生成的回答。原有 `node src/server.mjs` 在未设置 BASELINE_DIR 时仍为虚构演示。

## 本轮产物

目录：`outputs/local-baseline-v1/`（Git 忽略）。

| 文件 | 用途 |
|---|---|
| train.jsonl | 13,072 组训练／检索样本，6 月 13 日—10 月 4 日 |
| validation.jsonl | 1,832 组验证样本，10 月 5—15 日 |
| test.jsonl | 1,899 组测试样本，10 月 16—26 日 |
| profile.json | 仅使用训练部分本人消息的表达统计及证据 ID |
| index.json | 训练上下文的关键词倒排索引，BM25 排序 |
| quality-report.json | 处理计数、时间边界、来源校验及输入哈希 |
| memory.json | 空事实记忆，等待人工审核后增加 |
| prompt.txt | 后续生成接口使用的提示词草案，尚未调用模型 |

125,997 条输入未发现重复来源 ID 或重复非零服务器 ID；9 条消息的邮箱／手机号被替换。109 个有消息的日期按时间约 80%/10%/10% 划分。以午夜或超过 30 分钟空档切分为 745 个会话；同发送者两分钟内连续消息合并，保留每条来源。

766 个没有直接对方前文的本人话轮不作为目标；1 个超长样本排除；11 个规范化重复上下文—回复样本排除；956 个包含较长保留集回复原文的较早集合窗口排除。常用短回复重复允许存在。

画像覆盖训练样本涉及的 46,987 条本人消息，平均 4.60 字、中位数 4 字，90% 不超过 8 字。这是该联系人场景的表达长度统计，不是人格判断，也不代表所有社交关系。

## 验证与限制

- 7 项 Node 测试通过，覆盖时间划分、原消息隔离、服务器 ID 精度与去重、测试回复隔离、索引身份核验等。
- HTTP 冒烟通过：首页及画像可读、检索返回 3 个训练示例、无效输入 400、外来 Origin 403。测试服务已停止。
- 未进行浏览器自动化交互测试、语义近似去重、模型效果评测；基础脱敏不能清除全部身份信息。
- 本轮仅文本。缺失附件可能影响上下文含义；午夜及时间空档只是话题边界的近似。
- 相同来源消息不跨集合，规范化的最后一轮上下文—回复不跨集合；较长保留集回复的完整话轮匹配被过滤，但未检查任意子串或语义改写。
- 事实记忆为空；未训练模型，没有生成式聊天能力。

## 重建

```powershell
node scripts/build-local-baseline.mjs outputs/wechat-export-20261026T051447794004Z/normalized.json outputs/local-baseline-v2
node --test tests/*.test.mjs
```

输出目录必须尚不存在，以免覆盖旧版本。服务器 ID 按字符串保留，避免 JavaScript 数字精度损失。重建后按需要把 BASELINE_DIR 指向新目录。
